# 직접 써 보기 — 클릭 순서 (약 30분)

자동 시연은 가상 마우스로 확인했다. 실제 마우스로 눌러 보고, 이상한 곳은 번호와 함께 적어 주면 고친다.

> 2026-11-27: 개발자가 실행 파일(`CivilTwin.exe`)을 실제 마우스로 써 보고 "클릭된다"고 확인했다. 아래 20개 항목을 하나하나 확인한 기록은 아니다.
> 사용법 전체는 [MANUAL.md](MANUAL.md) (메모장용 [사용설명서.txt](사용설명서.txt)).
Unity Hub에서 프로젝트를 열고(인수 `-force-vulkan`), `Assets/Scenes/SampleScene`에서 ▶. 또는 `Builds\Windows\CivilTwin.exe -force-vulkan`.

## A. 처음 화면과 메뉴 (3분)
1. 오른쪽 위 메뉴의 현장 이름을 누른다 → 현장 10개(회사 8 + 랜드마크 + 시험용 언덕) 목록이 펼쳐지는가.
2. **1. 현대건설 · 소양강댐**을 고른다. 마우스 드래그로 돌리고, 휠로 확대한다.
3. 지형을 두 번 클릭 → 거리·경사가 나오는가. `C`로 지운다.

## B. 토공·건물·대안 (7분)
4. **[대안] → 예시 불러오기** → 아래에 대안 비교표(A 619 · B 381 · C 334일)가 나오는가.
5. **[재생] → 재생** → 굴착기가 트럭에 싣고, 트럭이 흙을 붓는가. 끝까지 가면 건물이 층별로 올라가는가.
6. **[대안] → 보고서 저장** → 화면 가운데에 파일 이름이 잠깐 뜨는가 (`Reports` 폴더).
7. 정보 글상자 오른쪽 위 **[접기 ▴] / [펼치기 ▾]**가 눌리는가 (2026-11-26에 실제 마우스로 안 눌리던 문제를 고침 — 꼭 확인).

## C. 소양강댐 시공 단계 (7분)
8. **[대안] → 댐 네트워크 공정표** → 작업 이름(예: 여수로)을 누르면 아래 설명이 바뀌는가. **[+30일]**을 누르면 논리 준공이 늘어나는가.
9. **[존 단면 보기]** → 단계 버튼 1 ~ 12를 하나씩 누른다. 고른 버튼에 바탕색이 칠해지는가.
10. **[▶ 다음 단계까지]** → 한 달씩 가다 다음 단계에서 멈추는가.
11. **10 8·19 홍수**에서 오른쪽 위 **[마루 도달: 11.10 (완공)]**을 누르면 8·19로 바뀌고 단면 높이가 123 m가 되는가.
12. **[3D로 보기]** → 3D에서 단계 버튼, **[반 잘라 존 보기]**, **[작업 자리로]**.

## D. 다른 회사 구조물 (8분) — 현장 목록에서 고른 뒤 [대안] 메뉴
13. **3. 부항댐**: 댐 네트워크 공정표 → [단계 보기] → 8 표면차수벽 → 1개월 ▶ 몇 번 (상류면 슬래브가 아래부터).
14. **4. 인제양양터널**: [부지] → 인제양양터널 굴착 → `Space` 재생. 그다음 [대안] → 터널 네트워크 공정표 → [단계 보기] → 5 굴착 절반 (막장 4개).
15. **6. 청계산 구간 / 8. 미사터널**: [부지] → 청계산3터널 굴착 / 미사터널 굴착 → `Space`. 글상자에 "실제 굴착 기간 비공개"가 보이는가.
16. **2. 청송양수 / 5. 예천양수**: 댐 네트워크 공정표 → [단계 보기] → 두 댐 단면과 아래 지하 작업 막대.

## E. 랜드마크 인천대교 (3분)
17. **9. 랜드마크 · 인천대교**: [대안] → 교량 네트워크 공정표 (논리 1,182일 ↔ 실제 1,553일).
18. [단계 보기] → 3 주탑 오르기 → 5 상판 내밀기 → **[3D로 보기]** → 마우스로 돌려 본다 → 8 준공.

## F. 화면 (2분)
19. **[화면] → 글자 크기 크게** → 글이 상자 밖으로 나가지 않는가. **처음 상태로**.
20. `F1` 키 안내, `Tab` 글상자 숨기기.
