> 목적: "댐이 차례차례 어떻게 지어지는가"를 실제 공정 순서대로 한 단계씩 보여 주고, 네트워크 공정표(CPM)로 공정 논리를 설명한다.

## 3. 네트워크 공정표 (CPM)

- 작업: 준비 → 가배수터널 1 → 유수전환 → 기초굴착 → 기초처리 → 성토 → 가배수터널 폐쇄·담수 → 준공 / 병행: 가배수터널 2, 여수로, 발전소.
- 기간: **실제 날짜(위 표)로 기준 공정**, 성토는 장비 계산값과 비교 (지금 8,024일 계산 ↔ 실제 약 924일 → 장비 205대 규모 차이를 설명).
- 화면: 가로 = 날짜(1967 ~ 1973) 위에 작업 상자와 화살표 (실무의 "시간 눈금 네트워크"), 주공정 빨강, 여유 표시. 단계 보기와 연결 (지금 단계가 표에서 강조).
- 판단 예: "가배수터널이 늦으면 유수전환 → 성토 → 전체가 늦어진다 (주공정)", "발전소는 준공 뒤 1973.11 완료 — 여유가 아니라 늦음".

## 3-1. 검토 (2026-11-22, 개발자 요청 "적합한지 검토하고 시작")

- **목적에 맞나:** 건설사 신입이 실제로 하는 일(공정표 작성·주공정 관리, 시공 순서 이해, 수량·장비 검토)과 직접 이어진다. 화려한 그래픽보다 "공정 논리를 숫자로 설명"하는 것이 강점이 된다 → 적합.
- **약점 1 — 실제 날짜만 다시 보여 주면 "재생기"일 뿐 시뮬레이션이 아니다.** → 실제 날짜로 기간을 잡고, 공사 논리로 CPM을 계산해 **논리 공정과 실제 공정을 비교**한다. Python 시제품 결과: 논리 공정은 본댐 성토 끝(1972.11.10, 2,036일)에 끝나지만 실제 준공은 2,375일. 여수로는 여유 361일이 있었는데 실제로 여유를 232일 넘겨 늦게 시작(1969.10.15)해 1973.6.30에 끝났다 → "본댐 다음으로 공사 기간을 정한 것은 여수로"라는 분석이 나온다. 그리고 "이 작업이 30일 늦으면?"을 바로 계산할 수 있다.
- **약점 2 — 단면 치수가 없다.** 존 단면은 가정으로 만들고 표시. 단면 그림을 구하면 바꾼다.
- **약점 3 — 3D를 10단계 모두 만드는 것은 크다.** → 효과가 큰 2D부터: ① 공정 자료·CPM(완료), ② 네트워크 공정표 화면, ③ 존 단면 화면, ④ 단계별 3D.
- **주의:** 여수로가 늦게 시작한 이유(설계 변경 1968.8, 자재·인력 등)는 자료에 없다. "늦게 시작했다"는 사실만 말하고 이유는 추정하지 않는다. 기초굴착·그라우팅·준비공사의 끝나는 날은 다음 작업 시작으로 둔 가정이다.
