# CIVIL TWIN은 어떤 프로그램인가 (한 장 소개)

## 한 줄로

**실제 지형 위에서 공사를 날짜별로 재생하고, 조건을 바꾸면 공기와 비용이 어떻게 달라지는지 비교하는 3D·4D 시공계획 및 대안 분석 프로그램.**

## 왜 만들었나

시공계획은 숫자로 결정됩니다.
- 장비를 몇 대 넣을지
- 어느 작업이 늦으면 준공이 늦어지는지
- 계획한 공기가 현실적인지

교과서의 공식(토공량, 장비 작업량, CPM)을 실제 현장에 직접 적용해 보고, 그 결과를 실제 공사 기록과 비교해 보려고 만들었습니다. 목표는 화려한 화면이 아니라 **"모든 숫자를 손계산으로 설명할 수 있는 프로그램"**입니다.

## 무엇을 할 수 있나

| 기능 | 내용 |
|---|---|
| 실제 지형 | 위성 지형 자료(30 m 간격)를 미터 좌표로 바꿔 만든 3D 현장 9곳 |
| 토공 계획 | 부지 높이에 따른 절토·성토량, 토량환산계수, 균형 계획고 자동 탐색, 토사·암 구분 |
| 장비 계획 | 표준품셈 식으로 굴착기·덤프트럭 작업량 계산. 공기는 굴착과 운반 중 느린 쪽 |
| 4D 재생 | 날짜별로 지형이 깎이고 건물이 층별로 올라감. 장비가 실제 순서로 움직임 |
| 공정표 | CPM(가장 빠른·늦은 시작일, 여유, 주공정선), 작업을 늦추면 준공이 어떻게 바뀌는지 |
| 대안 비교 | 조건 A·B·C를 저장해 공기·비용·주공정선 비교, 그래프 |
| 회사 구조물 | 국내 건설사 8곳이 시공한 구조물(댐 2, 양수발전소 2, 터널 4)과 랜드마크 인천대교를 공개 자료로 다시 만들어, 네트워크 공정표·시공 단계·3D·보고서로 보여 줌 |
| 보고서 | 계산 결과, 가정, 출처를 문서(Markdown)와 엑셀용 표(CSV)로 저장 |

## 어떻게 믿을 수 있나

- **손계산과 비교:** 계산 코드를 화면과 분리했고, 손계산 값과 비교하는 자동 테스트 389개로 검증했습니다.
- **출처 대조:** 계수와 장비 단가는 2025년 적용 건설공사 표준품셈과 건설기계 기계경비 산출표의 원문과 대조했습니다. 처음에 쓴 값 가운데 표에 없던 것은 원문 값으로 고쳤습니다.
- **가정 표시:** 자료가 없는 값은 화면과 보고서에 **"가정"**으로 표시했습니다. 어느 숫자가 자료이고 어느 숫자가 가정인지 구분할 수 있습니다.
- **화면 검산:** 자동 시연 도구로 화면과 글상자의 숫자를 저장해 검산했습니다.

## 만든 도구

Unity 6.3 LTS (URP), C#, NUnit, QGIS 3.44 (GDAL), Git. 코드는 AI 코딩 도구(Claude Code)의 도움을 받아 작성했습니다. 직접 한 일은 다음과 같습니다.
- 계산 방법 정하기
- 손계산으로 테스트 값 만들기
- 화면 숫자 검산하기
- 자료 출처 확인하기

## 한계

- **용도:** 실제 설계·공정 프로그램을 대신하려는 것이 아닙니다. 학습·포트폴리오용입니다.
- **지형 정밀도:** 위성 지형은 30 m 간격이라 설계 정밀도가 아닙니다.
- **비용:** 장비비와 기간 비례비만 더한 비교용 일부 항목입니다.
- **기간:** 구조물 공정에서 자료가 없는 기간은 표준 값으로 채웠습니다(가정).
