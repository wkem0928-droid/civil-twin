# 모든 회사 구조물 + 인천대교 — 공통 시공 단계 틀 (2026-11-27)

개발자: "어느 곳에 지원할지 모르니까 싹 다 추가하고", "회사 아닌 곳에 지원할 때 쓸 거 하나 — 랜드마크·유명한 구조물로" → 인천대교.

## 1. 목표

8개 회사 구조물 모두 소양강댐과 같은 깊이로 만든다: **네트워크 공정표(CPM·지연 영향) → 단계 넘겨 보기 → 보고서**.
회사마다 코드를 복사하지 않고 **공통 틀 하나 + 구조물마다 자료 묶음**으로 만든다.

## 2. 자료의 현실 (2026-11-27 검색)

- 중간 날짜(유수전환, 성토 완료, 주탑 완공, 상판 연결 등)는 소양강댐 말고는 **공개 자료에서 거의 찾지 못했다.** 확인된 것은 대부분 착공·준공(개통)과 큰 제원뿐이다.
  - 인천대교: 기공식 2005.6.16, 착공 2005.7, 준공 2009.10, 개통 2009.10.16~26 보도 (국토교통부), 사장교 1,480 m · 주경간 800 m · 주탑 238.5 m(평균해수면, 기초 상면 230.5 m) · 선박 통과 높이 74 m, 2008.3 공정률 70 %, 2009.6 "상판과 구조물 모두 갖춰짐".
  - 예천양수: 2005.4 착공, 2011 완공, 대림산업, 상부댐 EL 711 m 저수량 685.6만 m³, 하부댐 EL 241 m 896만 m³ (매일신문). 댐 높이·체적·형식은 못 찾음.
  - 청송양수: 2000.9 착공, 2006 준공, 600 MW. 댐 높이·체적·형식 못 찾음.
  - 부항댐: 연혁 날짜 못 찾음 (준공 2013.11 준공식 / 논문은 2014 기준).
  - 미사터널·청계산 구간: 터널 길이·날짜 못 찾음 (서울~춘천 고속도로 공사 '05 ~ '09).
- 그래서 **"표준 공정"**을 둔다: 구조물 종류마다 교과서적 작업 순서와 선후행, 기간은 ① 자료의 날짜 → ② 계산(굴착·라이닝·성토량 ÷ 시공량) → ③ 표준 비율의 순서로 채운다. ②·③은 화면·보고서에 **가정**으로 표시한다.

## 3. 공통 틀 (코드)

- `Core/ConstructionSchedule.cs`: 작업(날짜·선행·출처·가정·무엇을/왜/장비), 사건, **단계(날짜·제목·설명)**, 구조물 종류, CPM·지연 영향 (지금 `DamConstruction.cs`를 이름만 일반화).
- `Core/ScheduleCatalog.cs`: 현장 파일 → 공정 자료 (구조물마다 자료 묶음 하나).
- `Core/ConstructionReport.cs`: 공통 절(요약·네트워크·논리 vs 실제·지연·단계·한계) + 구조물 종류별 절(댐: 성토 높이·존 물량·운반 검산 / 터널: 막장 공정 / 교량: 주탑·상판).
- 화면: `ScheduleView`(네트워크 공정표, 지금 화면 일반화), `StageView`(단계 넘기기 머리 부분은 공통, 그림은 종류별: 댐 존 단면 / 터널 종단면 / 교량 측면).
- 소양강댐은 기존 테스트 376개로 숫자가 바뀌지 않음을 확인하며 옮긴다.

## 4. 순서

1. 공통 틀로 옮기기 (소양강댐 그대로)
2. 부항댐 → 인제·산성 → 청송·예천 → 청계산·미사
3. 인천대교 (지형 파일 새로 만들기 — 내려받기는 개발자 확인 후)
4. 마감: 전체 시연, README, 실행 파일, 공개본
