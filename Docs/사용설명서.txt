 1. 어떤 프로그램인가
--------------------------------------------------------------------

  실제 지형 위에서 토공·건물·댐·터널·교량 공사를 날짜에 따라 재생하고,
  조건(장비 대수, 작업 시간 등)을 바꾸면 공사 기간(공기)과 비용이
  어떻게 달라지는지 비교하는 "시공계획 및 대안 분석" 프로그램입니다.

  - 3D : 위성 지형 자료(30 m 간격)로 만든 실제 현장 지형
  - 4D : 3D + 시간. 날짜를 움직이면 땅이 깎이고, 건물이 층별로 올라가고,
         댐이 쌓이고, 터널 막장이 나아갑니다.
  - 계산 : 토공량, 토량 균형, 장비 작업량(표준품셈 식), CPM 공정표,
           터널 1발파 싸이클, 댐 체적 등. 모든 계산은 손계산 값과 비교하는
           자동 테스트(389개)를 통과했습니다.

  현장은 국내 건설사 8곳이 시공(또는 참여)한 곳이고, 각 회사가 만든
  구조물을 공개 자료로 다시 만들었습니다. 회사와 관계없이 보여 줄 수 있는
  랜드마크로 인천대교(사장교)도 들어 있습니다.

     현대건설        소양강댐 (사력댐)                — 가장 자세함
     삼성물산        청송양수발전소
     GS건설          김천 부항댐 (표면차수벽형 석괴댐)
     대우건설        인제양양터널 (NATM)
     DL이앤씨        예천양수발전소
     롯데건설        청계산3터널 (안양~성남 고속도로)
     포스코이앤씨    부산 산성터널 (NATM)
     HDC현대산업개발 미사터널 (서울~춘천 고속도로)
     랜드마크        인천대교 (사장교)

  이 프로그램은 실제 설계·공정 프로그램(Civil 3D, Primavera P6 등)을
  대신하려는 것이 아닙니다. 시공계획의 계산 원리를 구현하고 검증해 보는
  학습·포트폴리오용 프로그램입니다.

 2. 실행하기
--------------------------------------------------------------------

  설치는 필요 없습니다.

  (1) 받은 압축 파일(zip)을 원하는 폴더에 풉니다.
      예: 바탕화면\CivilTwin
      ※ 압축을 풀지 않고 zip 안에서 바로 실행하면 지형 파일을 못 읽습니다.
  (2) 폴더 안의 CivilTwin.exe 를 더블클릭합니다.
  (3) 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면
      [추가 정보] → [실행] 을 누릅니다. (서명하지 않은 개인 프로그램이라 뜹니다.)

  폴더 안의 파일 (지우거나 옮기면 안 됩니다)
     CivilTwin.exe       프로그램
     CivilTwin_Data\     프로그램 자료
     Data\sites\         현장 지형 파일 9개 (.asc)
     UnityPlayer.dll 등  실행에 필요한 파일
     사용설명서.txt      이 파일

  필요한 환경: Windows 10/11 64비트, DirectX 11 또는 Vulkan을 쓰는 그래픽 카드.
  창 크기는 처음 1600 × 900이고, 창 가장자리를 끌어 바꿀 수 있습니다.

  화면이 검게 나오거나 바로 꺼지면 → 11절 "문제가 생기면"을 보세요.
  (오래된 AMD 그래픽 드라이버에서는 -force-vulkan 을 붙여 실행해야 합니다.)

 3. 화면 구성
--------------------------------------------------------------------

   ┌──────────────────────────────────────────────────────────┐
   │ 왼쪽 위: 측정 안내,             오른쪽 위: 메뉴           │
   │ 건물 글상자, 단면 등            ◀ 현장 이름 ▶             │
   │                                 [부지][장비][재생]...     │
   │                                                          │
   │            가운데: 3D 지형      오른쪽: 정보 글상자       │
   │                                 (계산 결과 숫자)          │
   │                                                          │
   │ 아래: 시간 막대 (재생할 때), 터널이면 종단면              │
   └──────────────────────────────────────────────────────────┘

  - 메뉴는 오른쪽 위에 있습니다. 메뉴 이름을 누르면 그 아래에 버튼이
    펼쳐지고, 다시 누르면 접힙니다.
  - 버튼 이름 옆 괄호 안은 같은 일을 하는 키입니다. 예: "부지 놓기 (G)"
  - 글상자 오른쪽 위의 [접기 ▴] 를 누르면 핵심 숫자 한 줄만 남고,
    [펼치기 ▾] 로 다시 펼칩니다.
  - 회색으로 흐린 버튼은 지금 쓸 수 없는 버튼입니다
    (예: 부지를 놓기 전에는 재생 버튼이 흐립니다).

  카메라
     왼쪽 버튼 드래그   돌리기
     오른쪽 버튼 드래그 옮기기
     마우스 휠          확대·축소
     W A S D            옮기기
     R                  처음 시점으로

 4. 처음 5분 따라 하기
--------------------------------------------------------------------

  처음이라면 이 순서대로 해 보세요. 대표 예시가 버튼 하나로 만들어집니다.

  (1) 메뉴 [대안] → "예시 불러오기: 가상 부지 + 5층 건물, 장비 A · B · C"
      → 소양강댐 현장 지형 위에 "가상의 부지"를 놓고 5층 건물을 짓는 예시입니다.
        댐을 짓는 것이 아닙니다 (댐은 6절: [부지] → 소양강댐 쌓기).
        땅을 깎고 메우는 토공 계획과 장비 조합을 익히려고 만든 예시라서
        실제 지형이 있는 현장을 빌려 썼습니다.
      → 부지와 건물이 놓이고, 장비 조합 세 가지가 저장되고,
        왼쪽 아래에 대안 비교표가 나옵니다.

          대안  굴착기  덤프트럭  전체 공기
           A     4대     4대      619일   (트럭이 모자라 굴착기가 기다림)
           B     4대     8대      381일
           C     8대     8대      334일   (굴착기를 두 배로 해도 47일만 줄어듦)

      → "장비는 대수가 아니라 조합으로 계획해야 한다"가 숫자로 보입니다.

  (2) 메뉴 [재생] → "재생 (Space)"
      → 굴착기가 덤프트럭에 흙을 싣고, 트럭이 흙을 붓고, 땅이 깎입니다(약 10초).
        토공이 끝나면 건물이 층별로 올라갑니다(약 25초). 아래 시간 막대가 날짜입니다.
        건물이 작게 보이면 [건물] → "부지 가까이 보기 (F)".

  (3) 메뉴 [건물] → "공정표 보기 (P)"
      → 왼쪽에 건물 공사의 CPM 공정표(가장 빠른·늦은 시작일, 여유, 주공정선)가
        나옵니다. 같은 자리를 쓰는 대안 비교표는 닫힙니다.
        비교표를 다시 보려면 [대안] → 비교 화면 (O) 의 [바꾸기].

  (4) 메뉴 [대안] → "댐 네트워크 공정표 (시공 순서 · CPM)"
      → 이제 진짜 댐입니다. 소양강댐을 실제로 지은 순서(1967 ~ 1973)를
        공정표로 봅니다.
        이어서 "존 단면 보기" → 단계 버튼 1 ~ 12 를 하나씩 눌러 보세요.

  (5) 메뉴 [대안] → "보고서 저장"
      → 계산 결과가 문서로 저장됩니다 (8절).

 5. 위쪽 메뉴 하나씩
--------------------------------------------------------------------

  ■ 맨 윗줄: ◀  현장 이름  ▶
     - ◀ ▶ (또는 [ ] 키) : 이전·다음 현장
     - 현장 이름을 누르면 현장 10개 목록이 펼쳐지고 바로 고를 수 있습니다.
       (회사 8곳 + 랜드마크 인천대교 + 시험용 수식 언덕)
       [댐] [터널] 표시는 그 현장에 구조물 모드가 있다는 뜻입니다.

  ■ [부지] — 땅을 평평하게 만들 자리(부지)를 정합니다
     - 부지 놓기 (G)             : 화면 가운데에 부지를 놓습니다
                                   (G 키는 마우스가 가리키는 곳에 놓습니다)
     - 부지 지우기 (H)
     - 계획고 −10 −1 +1 +10      : 부지를 만들 높이(m). 바꾸면 절토·성토량이
                                   바로 다시 계산됩니다
     - 균형 계획고 찾기 (E)      : 깎은 흙을 다져서 쌓을 곳을 딱 채우는 높이를
                                   찾습니다 (절토 × C = 성토)
     - 부지 크기 (9 0)
     - 암반선 깊이 (X)           : 없음 → 1 → 2 → 5 → 10 → 20 m.
                                   암을 넣으면 굴착이 느려지고, 암을 깨는 데
                                   필요한 브레이커·발파 장비 대수가 나옵니다
     - 보는 면 (V)               : 계획면 / 원지반 / 공사 중
     - 댐 현장(소양강댐, 부항댐) : "○○댐 쌓기 (공개 제원)" 버튼이 생깁니다
     - 터널 현장                 : "○○터널 굴착 (NATM)" 버튼이 생깁니다

  ■ [장비] — 장비 조건을 바꿉니다 (바꾸면 공기가 바로 다시 계산됨)
     - 굴착기 대수, 덤프트럭 대수, 하루 작업 시간, 장비 간섭 가정
     - 토공 공기 = 굴착과 운반 중 느린 쪽
     - 터널 보기 중에는 터널 조건으로 바뀝니다:
       하루 작업 시간, 로더 대수, 가운데 사갱 사용, 라이닝 거푸집 조 수,
       용수(지하수) 할증 +30 %, 라이닝을 굴착과 병행할지

  ■ [재생] — 4D 재생
     - 처음 (B), ◀ 하루 (N), 재생/멈춤 (Space), 하루 ▶ (M)
       (터널은 10일씩)
     - 재생 속도: × 0.5 · 1 · 2 · 4

  ■ [건물] — 부지 위의 건물과 장비
     - 건물·장비 보기 (T), 층수 (K L), 부지 가까이 보기 (F),
       공정표 보기 (P)

  ■ [대안] — 조건을 저장해 비교하고, 구조물 공정을 봅니다
     - 예시 불러오기             : 가상 부지 + 5층 건물 예시 (4절, 댐 아님)
     - 지금 조건 저장 A B C (1 2 3 키), 불러오기 (Shift + 숫자)
     - 비교 화면 (O) [바꾸기]    : 비교표 → 그래프 → 닫기
                                   (금액은 1억 원 이상이면 "32.5억"처럼 억 원으로)
     - ○○ 네트워크 공정표        : 회사 구조물 현장에서만 (7절)
     - ○○ 시공 단계 (한 단계씩)  : 회사 구조물 현장에서만 (7절)
     - 보고서 저장               : 8절
     - 자동 문장                 : 마지막 대안과 지금 조건을 비교한 문장
       예) "A → B (덤프트럭 4대 → 8대): 전체 공기는 619일 → 381일(238일 단축) ..."

  ■ [화면] — 보이는 것을 정리합니다
     - 글상자 내용 간단 / 자세히
     - 한꺼번에 줄이기 (Tab)
     - 글자 크기: 작게 · 보통 · 크게 · 아주 크게
     - 항목별 켜기·끄기: 정보 글상자, 측정 안내, 표고 범례, 누적 토공 그래프,
       터널 단면 모식도, 이름표, 시간 막대·종단면
     - 처음 상태로, 키 안내 (F1), 화면 저장 (F12)
     - 고른 설정은 다음 실행에도 남습니다.

  ■ 거리·경사 재기
     지형을 한 번 클릭하고 다른 곳을 한 번 더 클릭하면 두 점 사이의
     거리, 높이 차, 경사가 나옵니다. C 키로 지웁니다.

 6. 회사 구조물과 랜드마크 보기
--------------------------------------------------------------------

  현장 이름을 눌러 현장을 고른 뒤, 아래 메뉴를 누릅니다.

  ① 현대건설 · 소양강댐 (사력댐, 1967 ~ 1973)
     - [부지] → 소양강댐 쌓기 (공개 제원) : 공사 전 계곡을 복원하고 댐을 쌓음.
       계산 체적 9,395,915 m³ ↔ 공개 9,591,200 m³ (−2.0 %)
     - [대안] → 댐 네트워크 공정표 : 실제 공사 순서 10개 작업, CPM
     - [대안] → 댐 시공 단계 · 존 단면 : 12단계, 점토 코어·필터·사력 존,
       [3D로 보기]에서 같은 단계를 3D로, 장비가 작업 자리에서 움직임
     - 오른쪽 위 [마루 도달: 11.10 / 8·19] : 서로 맞지 않는 두 기록을 바꿔 가며
       비교 (8·19 홍수 때 이미 123 m였다는 기사 ↔ 완공 1972.11.10)

  ② 삼성물산 · 청송양수발전소 / ⑤ DL이앤씨 · 예천양수발전소
     - [대안] → 댐 네트워크 공정표 → [단계 보기]
       산 위 상부댐 + 산 아래 하부댐 두 단면과, 아래 지하 작업(발전소·수로)
       진행 막대. 주공정은 준비 → 지하 발전소 굴착 → 발전설비 → 시운전.

  ③ GS건설 · 김천 부항댐 (표면차수벽형 석괴댐)
     - [부지] → 부항댐 쌓기, [대안] → 댐 네트워크 공정표 → [단계 보기]
       → "표면차수벽" 단계에서 [1개월 ▶] 를 몇 번 누르면 상류면 콘크리트
       슬래브가 아래부터 올라갑니다.

  ④ 대우건설 · 인제양양터널 (NATM, 10,965 m)
     - [부지] → 인제양양터널 굴착 (NATM) → Space 로 재생
       양 입구 + 가운데 사갱에서 막장 4개가 나아감.
       계산 관통 927일 ↔ 실제 878일 (+5.6 %)
     - [장비]에서 사갱을 끄면 막장 2개로 1,420일. 사갱을 판 이유가 보입니다.
     - [대안] → 터널 네트워크 공정표 → [단계 보기]

  ⑥ 롯데건설 · 청계산3터널 / ⑦ 포스코이앤씨 · 산성터널 / ⑧ HDC · 미사터널
     - [부지] → ○○터널 굴착 → Space
     - 실제 굴착 기간(관통일)이 공개되지 않은 터널은 계산만 보여 주고
       실제와 % 비교는 하지 않습니다 (글상자에 그렇게 적힘).

  ⑨ 랜드마크 · 인천대교 (사장교, 2005 ~ 2009)
     - [대안] → 교량 네트워크 공정표 : 논리 공정 1,182일 ↔ 실제 1,553일
     - [단계 보기] → 주탑 오르기 → 상판 내밀기 → [3D로 보기]
       실제 노선 위에 그날까지 다 된 상판·교각·주탑·케이블이 보입니다.


--------------------------------------------------------------------
 7. 네트워크 공정표 화면과 시공 단계 화면
--------------------------------------------------------------------

  ■ 네트워크 공정표
     - 상자 하나가 작업 하나, 화살표는 "앞 작업이 끝나야 시작"입니다.
     - 빨간 상자가 주공정(하나라도 늦으면 준공이 늦어지는 작업)입니다.
     - 작업 이름을 누르면 아래에 무엇을·왜·어떤 장비로 했는지가 나옵니다.
     - [+30일] [−30일] : 고른 작업을 늦춰 보면 준공이 어떻게 바뀌는지
       다시 계산합니다. 여유가 있는 작업은 여유 안에서는 준공이 그대로입니다.
       [지연 지우기]로 되돌립니다.
     - "논리 공정"은 각 작업이 앞 작업이 끝나자마자 시작했다고 본 계산이고,
       "실제"는 자료의 날짜입니다. 둘을 나란히 보여 줍니다.
     - [존 단면 보기] 또는 [단계 보기] → 시공 단계 화면
     - [닫기 (Esc)]

  ■ 시공 단계 화면 (한 단계씩)
     - 단계 버튼을 바로 누르거나
       [◀ 이전 단계] [다음 단계 ▶], [◀ 1개월] [1개월 ▶] 로 넘깁니다.
     - [▶ 다음 단계까지] : 한 달씩 나아가다 다음 단계에서 멈춥니다.
     - [3D로 보기] / [단면으로 보기] (소양강댐), [측면으로 보기] (인천대교)
     - [공정표에서 이 날짜 보기] : 지금 날짜를 네트워크 공정표에서 봅니다.
     - 3D에서: [반 잘라 존 보기], [작업 자리로], [장비 숨기기], [처음 시점]
     - 화면에 "가정" 또는 "그림용"이라고 적힌 것은 자료가 없어 정한 값입니다.

 10. 숫자를 읽을 때 알아 둘 것
--------------------------------------------------------------------

  - 계수와 장비 작업량 식은 2025년 적용 건설공사 표준품셈에서 가져왔고,
    출처는 저장소의 Docs/ASSUMPTIONS.md 에 표로 정리했습니다.
  - 자료가 없는 값은 계산하거나 표준 값을 쓰고, 화면과 보고서에
    "가정"으로 표시했습니다. 공정 기간은 ① 자료의 날짜 → ② 계산 →
    ③ 표준 비율 순서로 채웠습니다.
  - 비용은 굴착기·덤프트럭 장비비와 기간 비례비만 더한 "비교용 일부
    항목"입니다. 실제 공사비가 아닙니다. 기간 비례비(50만 원/일)는 가정입니다.
  - 지형은 30 m 간격 위성 자료(DSM)라 건물·나무 높이가 섞여 있고,
    설계 정밀도가 아닙니다. 바다는 0 m로 평평하게 나옵니다.
  - 장비의 모양·움직임(관절 각도, 이동 속도, 대수)은 보기용입니다.
    공기 계산과는 따로 움직입니다.
  - 프로그램은 어느 대안이 "최적"이라고 정하지 않습니다. 숫자를 나란히
    보여 주고 판단은 사용자가 합니다.

 11. 문제가 생기면
--------------------------------------------------------------------

  ■ 실행하자마자 꺼지거나 화면이 검게 나올 때
     그래픽 드라이버 문제일 수 있습니다. Vulkan 그래픽으로 실행해 보세요.
       1) CivilTwin.exe 를 마우스 오른쪽 버튼 → [바로 가기 만들기]
       2) 만든 바로 가기를 마우스 오른쪽 버튼 → [속성]
       3) [대상] 칸 맨 끝에 한 칸 띄우고  -force-vulkan  을 붙인 뒤 [확인]
          예) "D:\CivilTwin\CivilTwin.exe" -force-vulkan
       4) 그 바로 가기로 실행
     그래픽 드라이버를 최신으로 바꾸는 것도 방법입니다.

  ■ 지형이 안 나오고 매끈한 언덕만 나올 때
     Data\sites 폴더의 지형 파일을 찾지 못한 것입니다. zip을 모두 풀었는지,
     CivilTwin.exe 옆에 Data\sites 폴더가 있는지 확인하세요.

  ■ 버튼이 안 눌리는 것 같을 때
     흐린 버튼은 지금 쓸 수 없는 버튼입니다. 예를 들어 [재생]은 부지를
     먼저 놓아야 하고, 네트워크 공정표는 회사 구조물 현장에서만 됩니다.

  ■ 글자가 너무 작거나 클 때
     [화면] → 글자 크기 → 바꾸기. 처음으로 돌리려면 [화면] → 처음 상태로.

  ■ 보고서가 어디 있는지 모를 때
     CivilTwin.exe 가 있는 폴더 → Reports 폴더.
